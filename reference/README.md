# reference/

External baseline data used for comparison against this study, not generated by this
project's own pipeline.

## ayyada_thesis_results.csv

Extracted from Youness Ayyada's M.Sc. thesis, University of Passau (Chair of Digital
Security, advised by Prof. Dr. Tolga Arul), dated 2026-03-25: *"Extensive Evaluation of
LM35 Temperature Sensors as Physical Unclonable Functions (PUFs) and True Random Number
Generators (TRNGs)."* Tables 6.1 (NIST SP 800-90B min-entropy) and 6.2–6.7 (NIST SP 800-22,
per-test pass/fail) for all 9 sensors (A1–A3, B1–B3, C1–C3) at 3.3V and 5V, using an
MCP3008 (10-bit ADC).

Columns:
- `MinEntropy_RAW_bits_per_bit` / `MinEntropy_VN_bits_per_bit` — SP 800-90B non-IID
  min-entropy, before/after Von Neumann extraction (his Table 6.1)
- `SP80022_{RAW,VN}_{Passed,Total,PassRate}` — aggregated across all 188 SP 800-22
  sub-test instances per sensor/voltage (his Tables 6.2–6.7), computed by summing pass
  counts across all 17 test categories (single-instance tests count as 1/1; multi-instance
  tests — Non-Overlapping Template, Random Excursions, Random Excursions Variant — use
  the N/148, N/8, N/18 counts as published)

His own summary (§7.1) states an overall min-entropy range of "~0.83–0.91 bits/bit for the
processed sequences," which matches this table (min 0.826, max 0.909) — a consistency
check on the extraction.

**Note on methodology differences:** he evaluated a single 1M-bit sequence per sensor/voltage
(not multiple streams), primarily at 24°C, vs. this study's multiple SP 800-22 streams
(25–100, depending on available bits) across 0/24/40°C. Both used the same underlying NIST
STS tool (188 sub-tests per run), so the per-run methodology is directly comparable, but the
temperature coverage differs — his numbers are effectively single-temperature.
